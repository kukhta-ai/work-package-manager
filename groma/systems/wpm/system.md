WPM is a Node.js command-line tool for authoring, validating and building portable agent instructions and work. The legacy bundle surface remains available while the isolated vNext surface introduces operations, independent group selection and optional worker setup. Development analyzers and repository agent skills are outside this product map. The CLI runtime container remains a draft because the scanner cannot match the package bin declaration to emitted source; its source components are scanned and curated.
